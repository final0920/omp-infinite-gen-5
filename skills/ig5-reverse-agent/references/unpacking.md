# 脱壳与产物验收

在任务要求恢复解包代码、导出内存映像或重建可运行文件时使用。当前工具是否支持产物重建，以实际 capabilities 和实现为准；本参考没有新增通用脱壳器或文件重建接口。

## 分清目标产物

| 产物 | 验收所需证据 | 保留的范围 |
|---|---|---|
| 可分析映像 | 同一目标/run/暂停身份的区域、权限、来源、空洞及 SHA，能定位目标代码 | 不要求独立运行；初始快照不证明后续自修改已捕获 |
| 可重新装载文件 | 真实导出文件摘要，独立格式/映射核对，入口和数据目录可解释 | 静态重开不证明可运行 |
| 受测可运行文件 | 已授权自产目标的隔离启动、完成/退出、受测输入输出及必要副作用 | 一次启动或一个输入不证明全输入域/全程序等价 |
| VM 业务恢复 | handler/控制流/内存/环境的范围、独立语义和路径覆盖证据 | 脱去外层压缩壳仍可能保留虚拟化字节码；各层分别报告 |

用户只要求分析时，不擅自扩大为运行或文件改写。用户已要求重建时，先用实际可用能力完成可审核产物；缺失模块则实现并验证，不把手写候选、图或伪代码称为已完成脱壳。

## 根据失效阶段推进

入口/OEP 是候选状态：保存初始入口、TLS/初始化、实际转移和区域解密来源，核对是否仍为加载器或 VM 入口。不依据高熵下降、可执行页出现或一次跳转就断言 OEP。运行时 VA、首选 VA、RVA 和文件偏移显式转换，保留模块基址与映射歧义。

启动和断点等待先按[原生证据判断](evidence.md)核对普通交互、安装与实际命中；PE 入口、受保护函数入口、函数返回点和进程终态分别记录。调整断点安装阶段或交互条件时保存变化，其余条件保持可比较；只有前次运行已确认终止，才开展新的受控运行。

内存布局与磁盘布局分别处理。页内可读不代表其文件映射、节大小/对齐或全部字节已恢复；空洞不可补零冒充观察。重建若涉及导入、转发导出、API-set、延迟导入、重定位、TLS、异常展开、节权限或加载配置，逐项写明已验证、未知或不适用及依据，不能将未处理的目录机械复制后默认有效。

导入候选保持模块/导出身份与歧义，实际调用绑定才是观察。导入表修复不证明所有运行时解析调用已恢复。重定位需要区分已应用与待应用状态，不能对已重定位内存重复处理。异常/TLS/初始化的缺口也不能用“主函数似乎能跑”消除。

修改写到任务产物目录，保留原样本与派生关系，核对实际导出字节；不改原保护器、许可或全局安全设置。公开写入和执行沿用宿主审批与既有预算，不能因外部工具没有审批接口而直接绕行。

复验必须针对本次产物：核对摘要，静态重新装载并检查目标地址/引用；在允许执行的自产验收范围内，才进行隔离运行和对照。装载失败返回具体阶段，运行失败保留真实事件和清理状态，不反复重试同一命令。未知/未支持项继续进入 Goal 的下一步，不能从报告删除。

外部项目的适用边界与来源要求见 [research-evaluation.md](research-evaluation.md)；VM 状态恢复见 [handler-semantics.md](handler-semantics.md)。
