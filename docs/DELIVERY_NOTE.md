# 无限五代（IG5）v1.2.0 交付说明

编制日期：2026-10-24。读者：交付方负责人、客户技术与安全评审人。
本说明以"能被核查"为原则：每一条结论都对应一个可运行的命令或一份文档。没有对应证据的内容一律写成"未验证"。

## 1. 这是什么

面向 DeepSeek Harness（DSH）的逆向分析插件与可视化工作台：静态分析（Ghidra）、原生调试（x64dbg）、单函数仿真、HTTP/HTTPS 本机采集、解密与协议分析、去混淆研究、调查状态管理。默认暴露 8 个工具（Core 8），按需展开到 40 个，其中 13 个会修改数据库或执行内容的工具每次调用都需要人工审批。

## 2. 必须先知道的三件事

1. **项目的大部分代码由 AI 代理生成**，规模很大（`source/` 下 164 个 JS 模块，另有 217 个 Python 文件；外部评审估算约 8.8 万行，本说明未独立统计总行数）。此前没有系统性的人工审查，测试也由同一类代理编写，存在同源盲点。
2. **人工审查尚未完成。** 安全关键代码共 36 个文件、约 1 万行（审批、租约、审计、采集代理、存储、子进程启动、脚本/调试/仿真执行器）。`docs/review/ledger.json` 记录每个文件的哈希与审查签字，**当前 5 个有效授权代理复审、31 个未签署**（bai 明确授权，Codex 实际执行；非真人亲审记录）。在签字完成之前，**不建议用于处理涉案或涉密数据的生产环境**。
3. **不是通用去混淆/去虚拟化工具。** 已验证的是自产样本上的局部结论；VMP 3.11 在本次环境未能重新运行；辅助模型（assist）没有测出收益，默认关闭。详见 `docs/LIMITATIONS.md`。

## 6. 建议的使用边界（在人工审查完成前）

- 仅用于**自有或已获授权**的样本与目标；不在含涉案/涉密数据的生产环境直接运行。
- **本机 DSH 设为自动批准（公司决定）。** 此时插件发出的审批请求会被立即通过，13 个审批门**没有人工把关**；所有脚本、补丁、调试、仿真、抓包控制操作都会直接执行。这意味着安全边界完全取决于：被分析的样本是否可信、脚本是否由可信的模型/人编写、worker 进程的系统权限（脚本无沙箱，见 R7）。**请只在隔离的分析环境里使用，不要在含涉案/涉密数据的环境里这样配置。** 对外材料请写"插件会发起审批请求；是否经人工确认取决于宿主策略"，**不要写"所有修改均需人工审批"**。
- 审批请求现在包含完整参数，在自动批准下仍会被宿主记录（预期行为，**未验证宿主是否持久化该文本**），可作事后追溯，但这不是防御。
- 所有审批弹窗中的脚本、字节、命令参数由审批人**逐条阅读**后再批准。
- 不开启 `assist`；不使用 Full 43 中未被评审的功能；不把输出当作最终结论，需人工复核。
- 抓包功能不将 CA 安装到系统信任库；抓包数据按所在单位的数据管理规定存放和销毁。
