# 实验性函数提升

`ig5_ir level=lift` 在独立的 Windows x64 分析进程中使用开源 [Mergen](https://github.com/NaC-L/Mergen)，读取原始 AMD64 PE32+ 文件并生成函数 LLVM IR。目标文件不会作为程序执行，不读取或修改静态引擎数据库。先通过 `ig5_profile toolset=full` 展开既有40工具，无新增审批或执行旁路。

```json
{"target":"C:\\samples\\owned.exe","level":"lift","ea":"0x140001000","initial_flags":"0x200","lift_inline":["0x140001060"],"max_blocks":512}
```

`ea` 和可选 `lift_inline` 为原始文件的首选 VA，不能混入 RVA、ASLR 运行时地址或未映射/BSS地址。内联地址最多16个、必须非零且唯一，后端进一步拒绝导入目标；不猜测全部函数均可内联。`initial_flags` 必填，十六进制 `0x0..0xfff`，零不会被默认值覆盖；仅为显式低12位初始模型，不自动绑定录制，不声称完整架构 flags 语义。其他 GPR 参数保持符号输入。`max_blocks` 为1..4096，默认512；不用 `action`、`max_instructions` 或其他数据库/kernel/trace参数。

输入经稳定文件读取与 SHA-256 快照，两个解析器在禁止写入/删除的文件句柄持有期间读取同一 blob。原始文件没有应用重定位、运行时补丁或录制内存。与已有录制不一致时应保留该差异，不能将原生映像悄悄重建为新的原文件输入。

Windows Job 在 CreateProcess 时原子分配，主线程确认 Job 归属后才恢复；子进程环境不继承 API 密钥，固定分析 argv 无 shell 或任意工具路径。最多两个独立请求，每个只容纳一个分析子进程、2GiB OS 私有内存上限、最多50秒计算并预留5秒退出清理，整个请求不超过60秒。输出文件大小每20ms观察，单文件最多4MiB有界导入；这不是文件系统硬配额，超出部分保留在所属作业目录并明确不导入。取消通过私有当前 nonce 控制消息传递，等待实际退出确认。宿主只在 ACK 与 worker 真实退出均确认后释放容量；worker 异常退出而无 ACK 时保持未知与占用。

返回固定 `status=partial`、`recoveryStatus=unverified`、`businessAccepted=false`、`wholeBinaryVerified=false`、`nativeTargetExecuted=false`、`databaseModified=false`。`process` 只表示分析工具的运行状态。`diagnosticsSummary` 保留完整警告计数、受限预览和提升统计；IR预览有明确截断。`reportPath/reportSha256` 绑定完整不可变报告，`outputRefs` 绑定优化前后IR、诊断和日志。生成IR、零警告或 LLVM模块合法均不能替代业务函数的独立等价、返回与覆盖验收。

候选内存地址的启发式枚举可能不完整。未获得独立完整性认证时，每个已知候选（包括首个）都要求地址相等，其他地址保留原始LOAD；不能将首候选值当成未知地址默认值。精确局部地址求值只沿已证明的同块存储转发与无特殊标记的整数运算，最多128次访问／16层，未知、poison/undef、溢出承诺及不支持的运算拒绝。完整245项默认／自定义微测试通过且启用flags检查；自产条件内存读取夹具旧版错误变为常量17，修复版保留读取，在显式字节内存模型中的完整返回值SSA通过全输入等价检查。此证明不覆盖LLVM函数内存属性、别名承诺或整个优化管线；启发式控制目标候选的完整性仍须独立核验。

控制目标启发式枚举与完整数值域分别判断。单/双目标快速路径必须覆盖独立有界数值域，且目标可映射；部分集合保留raw地址比较和未知默认分支。数值域分析最多128访问／16层／256候选与笛卡尔运算／256次同块存储扫描，缺失内存、循环、poison/undef或超限不认定完整。完整数值域仅约束该表达式，不能外推整函数语义。
