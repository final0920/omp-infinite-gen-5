# F00–01：证据与评测基础

实现标识：`20261024-fusion-foundation-1`。这是一组维护入口，不接入公共工具、GET路由或planner，不改变宿主实现标识、Core8/Full40、审批、预算、pins及界面。私有产物写在插件外的新目录，禁止导入共享knowledge-v1或分发包。

`scripts/fusion/evidence.mjs snapshot SOURCE_ROOT EVIDENCE_ROOT NEW_OUTPUT` 使用显式绝对路径。输出必须在两个输入树之外、父目录已经存在且末级目录不存在。源码枚举Git跟踪及非忽略未跟踪文件，保存实际文件字节、大小、SHA和Git状态；忽略的大型运行件不作为源码归档。证据树递归枚举所有普通文件，只保存路径/大小/SHA/mtime。拒绝链接文件、硬链接与读取期间可检测的身份变化，不执行输入文件。逐文件稳定读取不等于文件系统原子快照；不保证检测读后变化或恶意同时还原元数据的改写。

`scripts/fusion/build_vs_cases.mjs EVIDENCE_ROOT NEW_OUTPUT` 仅识别蓝图固定SHA的APK和so，按固定行范围生成16个原创摘要案例。原始全文、密钥、服务器、设备标识和最终答案不进入案例；源码冻结归档属于本地私有维护资料，不能发布。历史C:\RE\VS1.5路径只按相对路径和当前摘要建立映射，不证明历史文件系统身份。所有时间线均为回顾材料，历史当时可见输入未经证明。

案例包含问题、可见输入边界、观察、竞争假设、历史动作、结果位置、后来修正、未知、脱敏规则及开发归属。来源引用绑定完整文件SHA、起止行和统一LF行范围摘要；完整文件字节摘要保留CRLF差别。只有reported/contested，不接受旧报告的verified继承。

`scripts/fusion/audit_cases.mjs CASES_JSON EVIDENCE_ROOT NEW_RECEIPT` 重新读取原文件，验证来源字节与行范围。新回执文件使用wx，不覆盖旧证据。审计通过只说明引用完整性；是否支持文字结论由人工审阅，semanticVerified始终false。案例构建器是当前固定材料的定位器，文件变更应保留旧产物后另行审核，不自动迁移行号。

## 评测准备合同

`scripts/evals/fusion/protocol.mjs` 与旧评测注册表并存，使用A旧能力/B原文/C条件/D索引实验/E候选算法、每任务每组3次。固定模型、路由、采样参数、上下文、工具、语料、提示与总调用/token/时间/返回量预算；检索消耗包含在总成本中。家族跨开发与留出分区、重复输入、VS1.5进入holdout、重复运行、控制字段变化、日志/输入/裁判摘要失配均拒绝。声明家族不等于已经独立核实家族关系。

首份产物仅登记10个开发决策任务，尚未选择模型或正式留出集；没有运行模型。judgeDecisionEvents比较原始决策事件与固定期望，仅判工作流决策，不判算法等价。summarizeRuns要求评估者另供摘要匹配的期望并独立重放，否则计unknown，不能使用运行方提交的pass替代裁判。日志和裁判摘要绑定只能防意外混用，不是签名、执行环境隔离或可信oracle认证；攻击者控制评估进程时不可信。

当前答案边界固定exposed，blindRuns固定0，assistAllowed固定false；文件、终端、网络、检索、宿主缓存、历史及恢复代理边界仍待完整实测。旧semantic_discovery子进程文件权限探针可复用，但不因此升级宿主或网络隔离。30个留出任务/5家族/配对差异与置信区间、完整原生验证和真实模型收益尚未实现。

硬门预登记为错误接受与权限/预算越界0，非劣界限5个百分点，off性能开销10%。正式评测前必须另行冻结真实模型/输入/阈值依据；不能把当前准备合同的占位模型用于效果声明。
