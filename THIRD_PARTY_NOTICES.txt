Ghidra: https://github.com/NationalSecurityAgency/ghidra
The independent IG5 kernel links the pinned Apache-2.0 Ghidra SLEIGH and native
decompiler into adapters/kernel/native/ig5_decompiler.dll. This is attributed
upstream analysis code, with IG5-owned mapped-image/C ABI integration; it is
not a recreated commercial Reverse core. GNU BFD and the Java communication
shell are excluded. See adapters/kernel/NOTICE, native/Ghidra-LICENSE.txt,
native/zlib-README.txt and native/build-proof.json for component provenance.
Runtime retains LICENSE, NOTICE and component licenses from the official release.
The bundled Project.jar GhidraURL class and its Project-src.zip source entry
contain the IG5 local project path compatibility modification. Legal hidden
local directories such as .dsh are accepted; project/repository naming and
dot traversal restrictions remain. The patch, fixed upstream/modified source,
Apache-2.0 license, modification notice and per-entry/hash build proof are in
adapters/ghidra/local-project-path/ and runtimes/ghidra/licenses/ig5-local-project-path/.
Unrelated uncompressed JAR/source ZIP entries remain unchanged. The fixed
third_party/sources snapshots and their recorded hashes are not modified.

JPype: https://github.com/jpype-project/jpype -- wheel metadata/licenses retained.
The bundled python/pylib/org.jpype.jar is a modified JPype 1.5.2 support JAR,
not an unmodified upstream release. Original JAR/source, modified source,
unicode-bootstrap.patch, Apache-2.0 LICENSE, UPSTREAM-NOTICE and modification
NOTICE are retained in adapters/ghidra/jpype-patch/. The upstream source is
pinned to https://raw.githubusercontent.com/jpype-project/jpype/v1.5.2/native/java/org/jpype/JPypeContext.java.
The original support JAR from the pinned official wheel has SHA-256
a8c993bccb81392102fca126d4d716605cbda2c6df2846d42c92dc3672bfd4f2.
The patched JAR has SHA-256
ba2b5ce10f5e3ccd4dd92979f044ddc9067b4e40052349748dda296f6c38e700.
The IG5-specific bootstrap permits one fixed native extension filename and
resolves it through Java's Unicode working directory. Without that property,
upstream path handling is retained. The native extension is not rebuilt.
scripts/patch_ghidra_jpype.ps1 uses the bundled JDK javac --release 8 to replace
only JPypeContext and its nested class entries in the original JAR. Rebuild
source/JAR/patch hashes and origins are recorded in runtime.json.jpypeBootstrap
and licenses/ig5-jpype-bootstrap/provenance.json; seal_runtime_bundle.ps1 updates
the complete runtime inventory afterwards. This modified upstream component
retains its upstream license; IG5's NC condition does not replace it. Frozen
third_party/sources snapshots and their original hashes are not modified.
